## Supported versions

Sunsum is in early development and does not yet have a supported release.
Security fixes will be applied to the `main` branch until a release policy is
published.

## Report a vulnerability

Do not disclose suspected vulnerabilities in a public issue or discussion.
Use GitHub private vulnerability reporting from the repository Security tab.
If that option is unavailable, contact the repository owner privately through
their GitHub profile and request a secure reporting channel.

Include the affected component, reproduction steps, potential impact, and any
known mitigations. Do not access data that is not yours, disrupt services, or
perform destructive testing.

The maintainers will acknowledge a report as soon as practical, coordinate
validation and remediation, and credit reporters when requested and safe.
